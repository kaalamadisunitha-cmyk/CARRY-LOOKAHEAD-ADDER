# 4-Bit Carry Look-Ahead Adder Using Verilog HDL

## Overview

This project implements a **4-bit Carry Look-Ahead Adder (CLA)** using Verilog HDL.

A Carry Look-Ahead Adder is a high-speed arithmetic circuit designed to reduce the carry propagation delay found in a conventional Ripple Carry Adder.

Instead of waiting for the carry to propagate from one full-adder stage to the next, the CLA calculates the carry signals using **Generate** and **Propagate** signals.

This project includes the RTL design, an exhaustive self-checking testbench, simulation waveform, and documentation.

## Carry Look-Ahead Principle

For each bit position, two signals are calculated:

### Propagate

```text
P = A XOR B
```

### Generate

```text
G = A AND B
```

The carry equations are then calculated directly.

For a 4-bit CLA:

```text
C1 = G0 + P0C0

C2 = G1 + P1G0 + P1P0C0

C3 = G2 + P2G1 + P2P1G0
     + P2P1P0C0

C4 = G3 + P3G2 + P3P2G1
     + P3P2P1G0
     + P3P2P1P0C0
```

The sum equations are:

```text
S0 = P0 XOR C0
S1 = P1 XOR C1
S2 = P2 XOR C2
S3 = P3 XOR C3
```

The final carry is:

```text
Cout = C4
```

## Verification

The testbench performs exhaustive verification.

```text
16 possible values for A

```

Therefore:

```text
16 × 16 × 2 = 512 combinations
```

The expected result is calculated using:

```verilog
expected = a + b + cin;
```

The calculated result is compared with:



## Ripple Carry Adder vs Carry Look-Ahead Adder

| Feature             | Ripple Carry Adder    | Carry Look-Ahead Adder   |
| ------------------- | --------------------- | ------------------------ |
| Carry calculation   | Sequential            | Parallel                 |
| Carry propagation   | Bit-by-bit            | Look-ahead               |
| Speed               | Lower                 | Higher                   |
| Hardware complexity | Low                   | Higher                   |
| Design complexity   | Simple                | More complex             |
| Main advantage      | Simple implementation | Faster carry calculation |

The main advantage of the CLA is that the carry signals are calculated using Generate and Propagate logic instead of waiting for the carry to ripple through every bit.

---

## Advantages

* Faster carry calculation than a Ripple Carry Adder.
* Reduces carry propagation delay.
* Suitable for high-speed arithmetic circuits.
* Demonstrates important digital design concepts.
* Easy to extend to larger CLA architectures.

---

## Disadvantages

* Requires more hardware than a basic Ripple Carry Adder.
* Carry equations become more complex as the bit width increases.
* Larger CLA circuits require additional logic for managing the carry calculations.
